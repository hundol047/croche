## 구현된 경계

Expo 클라이언트는 `EXPO_PUBLIC_CROCHE_PROXY_URL`로 지정한 **사용자 서버의 전체 URL**에만 요청합니다.
이는 FailTwin이 정의한 프록시 계약이며 Croche의 공식 API 주소가 아닙니다.
`CROCHE_API_KEY`를 읽거나 전송하지 않습니다. 공급자 키는 향후 서버의 비밀 설정에만 둡니다.
공식 모델 ID 두 개와 유효한 프록시 URL이 모두 있어야 Real 어댑터를 선택합니다.

요청은 POST / application/json, 서버 세션 쿠키를 사용할 수 있도록 credentials: include입니다.
본문은 아래 필드입니다. 응답은 해당 작업의 MistakeAnalysis / Prediction / TrapProblem / Problem JSON입니다.

```json
{
  "model": "공식 워크스페이스에서 확인한 모델 ID",
  "system": "작업과 출력 스키마 지시",
  "user": "문제와 제출 답 또는 생성 조건의 JSON 문자열",
  "context": ["미리 선택한 관련 학습 기록"]
}
```

- HTTPS만 허용하고 로컬 개발의 loopback HTTP만 예외로 둡니다.
- URL의 인증 정보·query·fragment는 거부합니다.
- 프록시 요청 12초 제한과 AbortController, 어댑터 호출 15초 제한이 있습니다.
- 비정상 HTTP·JSON·과도한 응답을 거부하고, Zod로 작업별 출력을 검증합니다.
- 공급자 예외·응답 본문·학습자 입력을 로그나 실패 안내에 노출하지 않습니다.
- 설정 직후에는 ‘연결 미확인’, 프록시 JSON 응답 후에는 ‘응답 확인’, 실패 후에는 ‘연결 오류’로 표시합니다.
  이는 프록시의 응답 상태이며 공식 Croche 연결 인증이 아닙니다.
- 설정 부족은 ‘Mock AI · Croche 연결 불가’로 명시합니다. 설정된 Real 요청의 실패를 Mock 성공으로 바꾸지 않습니다.
- AI의 정답 판정이 로컬 채점과 다르면 저장을 거부하여 DNA를 보호합니다.
- 생성된 문제의 과목·학교급·난이도, Trap의 과목·학교급·목표 유형이 요청과 다르면 출제 이력을 예약하기 전에 거부합니다. 이는 로컬 계약 검증이며 실제 공급자 연결 확인이 아닙니다.

## 아직 필요한 구현과 정보

공식 문서 URL, SDK 또는 HTTP 규격, 워크스페이스와 실제 모델 ID가 필요합니다.
또한 배포 가능한 서버, 사용자 인증·인가와 공급자 비밀 키 설정이 필요합니다.
**인증 서버와 공식 Croche 서버 어댑터는 아직 구현·배포되지 않았습니다.**

향후 서버는 인증된 세션을 확인하고, 허용 모델·입력 길이·호출 횟수를 제한해야 합니다.
클라이언트가 보내는 system/model을 권한으로 신뢰하지 않고 서버에서 검증해야 합니다.
쿠키 세션에는 origin 허용 목록과 CSRF 방어, 교차 origin에는 제한된 CORS 설정이 필요합니다.
공식 규격에 맞춘 서버 어댑터에서만 공급자 키를 사용하고, 성공·실패·타임아웃·스키마 오류를 통합 검증해야 합니다.

현재 HTTP 프록시와 Real 서비스의 테스트는 fake transport/client를 사용합니다.
실제 SDK, 서버 인증, 모델 품질·비용·지연시간을 검증한 결과가 아닙니다.
