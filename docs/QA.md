서버 어댑터·인증·배포가 필요합니다. 여러 탭/기기 사이 저장 동기화도 아직 없습니다.

### 최종 프로덕션 브라우저

실제 Chromium에서 **375·430·768·1440px × 16개 = 64개 시나리오**를 검증했습니다.
375px 최종 실행 16개, 430/768/1440px 최종 실행 48개가 모두 통과했습니다. Web export의 파일을
정적 SPA 서버에서 실행했으며 Expo 개발 서버의 결과로 대체하지 않았습니다.

각 학교급의 6과목 × 3난이도(총 72개 선택 조합)를 네 화면 폭에서 모두 출제·정답 제출했습니다.
신규 프로필은 빈 DNA로 시작하고 정답 18건 후에도 DNA가 새로 누적되지 않습니다. 학교급/과목/난이도
복원과 객관식 선택, 한국사 연속 7회 출제의 차이, 실제 저장 실패 주입/재시도, 중립 학교 Trap 및
소진 상태를 확인했습니다. 소진 검사는 저장된 진행 번호를 테스트에서 끝으로 설정한 것이며
실제 10,000번 클릭했다는 뜻은 아닙니다. 대학의 마지막 문제 출제·소진 검증도 유지합니다.

기존 동등 수식 **3e^(-2x)** 정답, 판정 불가 입력의 DNA 보호, 재시도/새로고침의 사건 중복 방지,
데모 HIT·중립·교정과 리포트도 네 폭에서 통과했습니다. console/page 오류 0, 가로 넘침 0이며 기존
React Navigation의 pointerEvents 경고만 기록합니다. 오류 안내를 실제 소진/미지원 이유로 바꾸면서
회귀 테스트의 안내문 기대값도 갱신했습니다. 점수나 저장 보호 검증을 제거하지 않았습니다.
최종 캡처와 변경 이유는 [DESIGN](DESIGN.md)에 연결했습니다.

추가 키보드 확인: 375px의 고등학교 한국사 흐름에서 Enter로 과목·난이도·출제·제출,
Space로 보기 선택, aria-pressed 선택 상태, 답 입력→풀이 입력의 Tab 순서와 정답 결과를 확인했습니다.
