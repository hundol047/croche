# FailTwin · 90–120초 심사 데모

**AI가 당신의 실수를 먼저 예측합니다.** 개념을 설명하는 AI 튜터와 달리,
반복해서 틀리는 행동 패턴을 Error DNA로 기억하고, 같은 약점을 노리는 새 문제로 교정합니다.

현재 시연은 **Mock AI**입니다. 공식 Croche SDK·접근 정보가 없어 Real Croche는 미연결 상태입니다.
점수는 결정적 규칙의 위험 점수이며 검증된 확률이 아닙니다.

## 준비

```bash
cd failtwin
npm ci
npm run web -- --offline
```

브라우저로 앱을 열고 온보딩의 **심사용 빠른 데모**를 선택하세요.
이전에 데모를 했다면 홈의 **데모 처음부터 · 예시 기록 초기화**를 누르세요.
데모의 예시 DNA만 초기화하며 실제 사용자 기록은 보존합니다.
확신도는 아래 시나리오에서 기본값 **보통**으로 유지합니다.

## 발표 순서

| 시간 | 동작 | 설명과 실제 결과 |
|---|---|---|
| 0–15초 | 홈의 Error DNA 확인 | 예시 조건 누락 **83**, 성급한 판단 **72**, 계산 실수 **61**, 개념 혼동 **47**. “무엇을 모르는가보다 어떻게 틀리는가를 학습합니다.” |
| 15–40초 | **문제 풀기 → 공업수학 → 약분과 정의역** | `f(x)=(x²−1)/(x−1)`의 `f(1)`에 의도적 오답 **`2`** 입력. 풀이: **`x+1로 약분하고 x=1을 대입했어요.`** 제출. 원래 분모가 0인 조건을 놓쳤으므로 **조건 누락**, DNA **83→100**. |
| 40–55초 | **다음 실수 예측 보기** | 조건 누락의 예상 실수 위험도 **100/100**. 위험 점수이고 확률이 아님을 짚어주세요. 같은 제출은 새로고침해도 한 번만 반영됩니다. |
| 55–80초 | **이 유형 훈련하기 → 집중 훈련 시작** | 새 문제 `ln(x−2)+ln(5−x)`의 정의역. 의도적 오답 **`[2,5]`** 입력·제출 → **Prediction HIT**. 실제 정답은 `(2,5)`이며 로그의 진수는 0이 될 수 없습니다. |
| 80–100초 | **다시 도전** | 다른 내용의 `√(9−x²)` 정의역 문제. 정답 **`[-3,3]`** 입력·제출 → **Trap 극복**, 조건 누락 DNA **100→91**. 제곱근은 0을 허용합니다. |
| 100–120초 | **학습 리포트 보기** | 저장된 Trap 2회 중 예측 적중 1회 **50%**, 정답으로 마친 연습 **1회**, 현재 위험 DNA 조건 누락 **91**. “실수를 예측하고 시험 전에 교정하는 루프입니다.” |

`999`처럼 유형을 판별할 수 없는 오답은 HIT로 집계하지 않습니다.
신규 실제 사용자는 예시 DNA와 과거 추이가 없이 시작합니다.
반복 데모는 초기화 후 시작하세요. 유한한 문제를 사용하고 소진을 안내하는 Mock이므로 무한 생성 AI는 아닙니다.

## Croche 연결 경계

`CrocheAIService` → `MockCrocheAIService` / `RealCrocheAIService`,
`src/services/croche/client.ts`, `memoryStore`, tool abstraction, model policy를 유지합니다.
공식 SDK와 접근 정보가 제공되면 이 경계에서 구현하고 실제 통합 검증을 별도로 진행해야 합니다.
현재 SDK 이름·엔드포인트·모델 ID를 가정하거나 Real 호출 성공을 주장하지 않습니다.

주 시연 경로는 Expo Web입니다. 모바일 실기기·iOS development build는 검증하지 않았으며,
SDK 51을 최신 iPhone Expo Go에서 QR만으로 실행할 수 있다고 약속하지 않습니다.
