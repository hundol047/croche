## 정답과 출제 이력

- 고정 문항은 기본 → 응용 순서이며 보기 위치를 결정적으로 회전합니다. 정답은 수치·보기의 전체 문자열로 안전하게 채점합니다. Python 문항은 텍스트만 표시하며 코드 실행을 하지 않습니다.
- 새 ID는 `curriculum-v1:{unitId}:{index}`입니다. `v2`와 `school-v1`의 내용·정답·ID·출제 카운터는 바꾸지 않았습니다. 공개한 내용을 수정할 때는 새 버전 ID와 변경 기록을 사용해야 합니다.
- `curriculumProgress`에 단원별 다음 문항을 별도로 저장합니다. 동일 사용자 저장 큐에서 선택·예약을 한 번에 커밋하고, 새로고침 후에도 다음 문항 또는 소진 상태를 유지합니다. 동시 요청은 다른 문항을 배정합니다.
- 정답 분석의 ‘다음 문제 풀기’와 풀이의 뒤로 가기는 단원 목록으로 돌아가며 실제 선택한 전체 학년/특정 학년 필터를 유지합니다.
- 학습 저장 실패는 문항을 소비하지 않습니다. 세션 저장만 실패하면 화면 안에서 준비한 같은 문항을 재시도하여 출제 카운터를 추가로 늘리지 않습니다. 이 준비 상태는 메모리이므로 세션 저장 실패 직후 페이지까지 새로고침하면 예약한 미제출 문항이 건너뛰어질 수 있습니다. 사건/DNA는 답 제출 전 생성하지 않습니다.
- 잘못된 카운터(음수·소수·초과·null·배열 등)는 오류로 안내하고 원본을 보존합니다. 기존 시도 ID의 사건 중복 방지·판정 불가 DNA 보호는 그대로 사용합니다.
- 출제 이력은 사용자별 로컬 저장입니다. 여러 탭·기기 간 동시 쓰기나 계정/서버 동기화는 구현하지 않았습니다.

## 실제 기출 수록 절차

현재 공식 문제 PDF·확정 정답·이용 조건을 **한 건도 취득하지 못했습니다.** 알려진 공식 홈페이지 링크만 제공하며 특정 시험 원문·정답·라이선스를 확인한 것처럼 표시하지 않습니다. 자체 제작 수능형은 공식 기출 목록에 넣지 않습니다.

기출 자료와 재배포 권한이 확보되면 아래 도구를 사용할 수 있습니다.

```bash
cd failtwin
npm run content:prepare-exam -- .content-staging/exam/bundle.json
# 공식 원문·확정 정답·권리 주장을 사람이 확인한 뒤 로컬 출시:
npm run content:prepare-exam -- .content-staging/exam/bundle.json --release
npm run typecheck
npm test -- --ci --maxWorkers=2
npm run content:check
```

묶음 형식은 [기출 수록 계약](./EXAM_IMPORT.md)에 설명했습니다. 도구는 기관별 HTTPS 호스트·시험 종류·문항 식별자·정답 일치·자료 완전성 표시·원문/정답/권한 파일 SHA-256·이용 권한 기록의 구조를 검사합니다. 후보 파일 작성만으로 앱 목록을 바꾸지 않습니다. `--release`는 출처와 권한의 사실성까지 확인한 담당자가 수행해야 합니다. **구조와 파일 해시가 맞는다고 출처 주장·허가·전문가 자격의 진위를 증명하지는 않습니다.** 합성 테스트는 이 한계를 명시하며 실제 앱 자료를 변경하지 않습니다.

출시 파일과 증빙은 각각 `officialExamRelease.ts`, `officialExamReceipts.ts`이며 현재 둘 다 빈 목록입니다. 공개한 같은 ID의 내용을 덮어쓰지 않습니다. 수능·평가원 모의평가·한국사능력검정의 시험 종류를 구별하며 한국사능력검정을 수능 기출로 표시하지 않습니다. 현재 계약은 문자로 완전하게 표현할 수 있는 문항만 지원합니다. 긴 지문(2,000자 초과)·그림·듣기 자료가 필수인 문항은 생략하여 수록할 수 없으며 별도 표현/접근성 지원이 필요합니다.

외부 원문은 `.content-staging/`의 검토 자료로 두고 Git에 넣지 않습니다. 모든 학교·교육청 기출 제공처나 대학별 시험의 권리·연동을 구현한 것은 아닙니다.

## 한국사 감수

[감수 자료](./history-review/README.md)는 44개 사건의 연도·학습용 설명·내용 해시, 60개 학교급/난도/유형 조합의 경계 표본 180문항, 신규 한국사 56문항을 포함합니다. 공식 출처·문서 위치·근거 문장·검토자·승인일·승인 범위는 비어 있고 상태는 대기입니다. 실제 인용 사료가 아니라 자체 작성한 요약입니다.

- `npm run content:history-packet`: 원본과 맞는 검토 CSV/JSON/문서 생성
- `npm run content:check`: 검토 묶음이 현재 사건·문항·해시와 같은지 검사, 수록 도구 합성 회귀 10개 실행

생성 CSV/JSON은 원본 양식이므로 복사본에 검토 결과를 기록하고 보존합니다. 재생성 명령은 생성 양식을 갱신합니다. CSV에 이름을 입력한다고 전문가 감수가 자동 완료되지는 않습니다. 실제 역사 전문가가 세부 공식 출처와 사건의 해석·표현·학년 적합성·정답을 검토한 승인 기록이 필요합니다. 수정 후에는 새 버전으로 내고 그 해시에 대한 승인 범위를 기록해야 합니다. 자동 연표 계산·정답 검사는 전문가 감수와 분리합니다.
