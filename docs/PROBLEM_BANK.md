# 학교급별 문제 은행 · 2026-10-08


단원별 자체 문항을 별도로 추가했습니다: 126개 단원/252개 배치, 중복 본문·정답·보기를 합치면 168개입니다. 공식 교육과정 매핑은 작성안이고 실제 기출은 0개, 역사 전문가 감수는 미완료입니다. [상세 범위](CURRICULUM_AND_SOURCES.md)와 [감수 자료](history-review/README.md)를 확인하세요.

이번 보충은 장문 독해·실험 자료·조건부확률·좌표·Python 예외 처리를 포함한 자체 문항 26개와 일반물리 부호 Trap 2개입니다. Trap은 변형 은행/단원 문항 합계에 넣지 않습니다. 기존 공개 단원 문항의 본문·정답·ID를 바꾸지 않고 새 보충 단원 ID를 추가했습니다.

대학교 v2를 보존하고 별도 `school-v1`을 추가했습니다. 기본 문제 7개는 합계에서 제외합니다.

|---|---|---:|---:|
| 초등학교 | 수학·국어·영어·과학·사회·한국사 | 30,000 | 180,000 |
| 중학교 | 수학·국어·영어·과학·사회·한국사 | 30,000 | 180,000 |
| 고등학교 | 수학·국어·영어·통합과학·통합사회·한국사 | 30,000 | 180,000 |

| 전체 | 27개 학교급·과목 조합 | | **810,000** |

각 과목은 쉬움·보통·어려움 각 10,000개이며, 각 난이도에 5개 유형 × 2,000개 조건/지문 조합이 있습니다.
**81만 개는 독립 집필 문항·실제 기출·서로 다른 개념의 수가 아닙니다.** 학교급 사이에는 공통 개념과
자료가 있습니다. 중복 검사는 학교급·과목별 30,000개 전체 본문에 적용합니다. 학년·단원별 전 교육과정,
국어 문학/문법 전체, 생명·지구과학, 모든 탐구 선택과목, 실제 수능의 난도·시간 구성은 아직 제공하지 않습니다.
수능은 `contentOrigin: original-csat`와 `[수능형 · 자체 제작]`으로 표시합니다.

### 내용과 정답

- 수학: 초등 수·연산·분수·측정에서 중등 방정식·함수·확률, 고등 수열·미적분·경우의 수까지 단계별 유형.
- 국어: 자체 안내문·관찰 기록·일정·조건·반례 읽기. 난이도마다 찾을 정보와 규칙을 달리합니다.
- 영어: 학교급별 20개 핵심 어휘, 시제·주어 일치, 대명사, 시간 관계, 복합 조건. 난이도별 질문/문장 구성이 다릅니다.
- 과학: 초등 관찰·물질·회로에서 중등 물리/화학, 고등 열·역학·전기·반응량. 가상 모형과 조건을 명시합니다.
- 사회: 지도/조사 자료·의사 결정·비율·관찰과 인과·가상 정책/시장. 실제 통계나 법률로 제시하지 않습니다.
- 한국사: 44개 사건의 이름·연도·학습용 요약을 고정한 뒤 서로 다른 세 사건을 조합합니다.
  가장 먼저/나중, 순서, 기간, 두 번째 사건을 묻습니다. 쉬움은 연도를 함께 주고, 보통은 사건명,
  어려움은 요약 설명을 제시합니다. 요약을 실제 사료 인용으로 표시하지 않습니다.

수치 정답과 해설은 조건으로 계산합니다. 테스트의 별도 계산기는 **출력된 문제 본문**에서 조건을 읽어
새 수학 전 유형과 과학·사회 숫자 문제 전체 조합을 대조합니다. 국어/영어의 규칙·반례·일정·시제·참조
정답도 본문을 읽어 검증합니다. 어휘와 역사 사실은 고정 학습 자료입니다. 역사 주요 연도 17개를 별도로
검사하고 연도 중복·시간 순서·기간·보기 구성을 검사합니다. 역사적 사실 전체에 대한 외부 전문가 감수나
공식 문서의 전수 대조를 완료했다는 뜻은 아닙니다.

역사 추가 검토의 참고 기관은 [국사편찬위원회 한국사 콘텐츠](https://contents.history.go.kr/)입니다.
이번 환경에서는 공식 사이트 요청이 네트워크 프록시에서 차단되어 본문을 열지 못했습니다.
출처를 확인한 실제 사료 인용과 기출 수록은 후속 작업입니다.

### 저장·호환과 훈련

학교 문제 ID와 진행 번호는 `school-v1:{학교급}:{과목}:{난이도}:{유형}`으로 분리합니다.
대학 v2의 숫자 조합 순서·ID·45개 진행 번호는 유지합니다. 학교의 20×10×10 조합은 137을 곱한
순열과 유형별 271의 시작 간격으로 순회해 연속 출제의 조건/자료가 여러 축에서 바뀝니다.
학교 Trap은 별도 시작 위치(997)와 본문 이력을 사용합니다. 최대 360개 학교 진행 번호를 저장하며
81만 개의 본문 JSON을 미리 저장/번들링하지 않습니다.

원자적 출제 예약과 함께 최근 학교급·과목·난이도를 저장해 새로고침 후 복원합니다.
학교 문제의 예시 재풀기는 별도 목록으로 표시하고 새로운 출제와 구분합니다.
학습 사건·DNA에는 학교급도 저장합니다. 기존 기록에서 학교급이 없으면 대학 기록으로 해석합니다.
학교 Trap은 같은 학교급/과목/실수 유형의 다른 조건을 연습합니다. 근거 없는 오답은 중립으로 남기며
HIT/DNA를 추가하지 않습니다. 준비된 유형이 없거나 모두 소진되면 그 이유를 표시합니다.

## 대학교 v2 세부 구성 · 2026-10-08

공업수학·일반물리·Python 프로그래밍에 **과목당 30,000개, 총 90,000개**의 조건 조합 문제를 제공합니다.
기존 기본 문제 7개와 Trap 문제는 별도로 유지합니다.

| 과목 | 쉬움 | 보통 | 어려움 | 합계 |
|---|---:|---:|---:|---:|
| 공업수학 | 10,000 | 10,000 | 10,000 | 30,000 |
| 일반물리 | 10,000 | 10,000 | 10,000 | 30,000 |
| Python 프로그래밍 | 10,000 | 10,000 | 10,000 | 30,000 |

**90,000개의 독립 집필 문제나 실제 AI 생성 결과를 뜻하지 않습니다.**
과목·난이도마다 검증된 5개 유형을 두고 유형별 20×10×10 조건 조합 2,000개를 결정적으로 구성합니다.
전체 45개 유형이며, 모든 본문과 ID가 서로 다름을 검사했습니다. 같은 개념의 반복 연습을 위한
파라미터 문제이므로 서로 다른 개념이 90,000개라는 의미는 아닙니다.
화면에 ‘검증된 유형의 조건 조합 문제’, Mock AI·Croche 미연결을 표시하고 문제의 source는 bank로 저장합니다.

## 출제와 저장

- 화면은 과목·난이도 선택, 새 문제 풀기, 유형별 목록 순서입니다. 유형을 직접 선택할 수도 있습니다.
- 기본 출제는 진행 번호가 가장 작은 유형을 선택해 유형 간 연습을 균형 있게 배치합니다.
  같은 유형을 선택하면 다음 조건 조합을 출제합니다.
- 문제는 **한 개씩 계산**합니다. 90,000개 JSON이나 수만 개의 행을 앱 시작 시 읽거나 렌더링하지 않습니다.
- `practiceProgress`에 `v2:과목:난이도:유형`별 다음 변형 번호만 저장합니다. 전체 45개 번호가 4KiB 이내입니다(모두 소진된 v2의 JSON: 1,807 UTF-8 bytes).
  풀이·DNA·Trap 기록의 저장 크기까지 4KiB라는 뜻은 아닙니다.
- 선택·검증·번호 증가를 동일한 learning의 직렬화된 갱신에서 실행합니다.
  같은 런타임의 동시 요청은 서로 다른 문제를 예약하며, 저장 실패는 번호를 증가시키지 않습니다.
- 답을 제출하지 않고 나가도 열린 문제는 사용한 것으로 봅니다. 새로고침한 풀이 세션은 같은 문제를 복원합니다.
- 소진된 유형은 비활성화합니다. 난이도 전체가 소진되면 새 문제 버튼도 비활성화하고 다른 난이도·기본 문제를 안내합니다.
- 이전 버전의 issued 이력과 학습 기록은 그대로 보존합니다. 새 은행은 별도의 v2 본문·ID·진행 번호를 사용합니다.
  Trap은 기존 본문 이력 정책을 유지하고, 데모 초기화는 데모의 진행 번호만 지웁니다.
- v2 안에서 유형 ID와 변형 순서는 고정해야 합니다. 조건·정답·순서를 바꾸면 새 은행 버전으로 관리해야 합니다.

세션 저장은 출제 예약 뒤에 실행합니다. 세션 저장만 실패하면 문제 하나가 소진될 수 있습니다.
여러 브라우저 탭·기기 사이의 동기화와 전역 트랜잭션은 아직 구현하지 않았습니다.
