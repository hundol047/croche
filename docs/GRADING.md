## 재현한 오류와 수정

`y′+2y=0, y(0)=3`에 `3e^(-2x)`를 제출하면 이전 버전은 문자열 표기 차이로 오답 판정하고
부호 오류 DNA를 0→17로 누적했습니다. 현재는 `3e^{-2x}`와 같은 식으로 판정합니다.

`assessAnswer`는 정답 / 오답 / 판정 불가를 반환합니다. 풀이 화면에서 판정 불가를 안내하고,
분석 경로와 영속 저장 함수에서도 다시 검사합니다. 판정 불가는 풀이·Trap 사건, HIT, DNA 증가·교정에
반영되지 않습니다. 기존 확정 사건의 점수 엔진과 원자적 저장·중복 방지는 유지했습니다.

## 지원하는 답

| 답 | 처리 |
|---|---|
| 숫자 하나 | 부호·소수·지수 표기 허용, 기존 절대 오차 10⁻⁶ 유지 |
| 유한 구간 | 숫자 두 개와 (), []의 끝점 포함 여부를 각각 비교 |
| 지수함수 | `c*e^(k*x)` 형태. `3e^(-2x)`, `3*e^{-2*x}`, `3exp(-2*x)` 허용 |
| 정의되지 않는 값 | ‘정의되지 않음’, ‘정의 안 됨’, undefined 허용. 숫자 답은 오답 |
| 복수 선택 | 보기의 답을 쉼표로 구분. 순서·대소문자 차이 허용 |
| 그 외 텍스트 | 저장된 정답과 동일한 표기 및 단순 문자 출력 문제만 지원 |

계수·지수의 부호와 값을 구분하고 구간의 열린·닫힌 끝점을 유지합니다.
256자 초과, 깨진 괄호, 실행 코드, 지원 밖 복합 수식은 판정 불가입니다.
공백을 제거해 서로 다른 숫자를 이어 붙이지 않고, 숫자는 유효 숫자 최대 15자리로 제한합니다.
입력을 eval/Function으로 실행하거나 수식의 몇 지점만 대입해 동등성을 추정하지 않습니다.

일반 CAS가 아닙니다. 유리식·삼각함수·복합식·부등식·무한 구간 등의 다양한 동치 표기는 아직 지원하지 않습니다.
지원 밖 입력에는 오답 원인을 단정하지 않고 재입력 형식을 안내합니다.
과거 버전의 저장 기록은 자동으로 재채점하거나 삭제하지 않습니다.

## 반복 출제

기본 문제 7개는 유지하고, 추가 연습은 **과목당 30,000개, 총 90,000개**의 조건 조합 문제로 확장했습니다.
쉬움·보통·어려움별 10,000개이며 각 난이도에 5개 유형×2,000개 변형이 있습니다.
90,000개의 독립 집필이나 실제 AI 생성이 아닌 검증된 유형의 파라미터 연습입니다.
전체 유형·범위·정답 검증은 [문제 은행](PROBLEM_BANK.md)을 참고하세요.

유형별 다음 변형 번호를 사용자별 learning의 practiceProgress에 원자적으로 저장합니다.
숫자·조건을 바꿔 정답·해설을 구성하고, 문제를 한 개씩 계산하므로 수만 개의 JSON을 저장하지 않습니다.
기존 issued 이력은 보존하며 새 v2 문제 은행은 별도 ID·본문으로 관리합니다.
답을 제출하지 않아도 다음 출제에서 제외되고, 앱·서비스·저장 객체를 다시 만들어도 진행 번호가 유지됩니다.
소진된 유형·난이도는 비활성화하고 다른 난이도나 기본 문제로 안내합니다.
Trap은 기존 본문 이력에 출제를 기록하고 같은 문제의 재출제를 막습니다.
이미 열린 문제의 새로고침은 현재 문제를 복원하며 새 출제로 집계하지 않습니다.

출제 이력 저장은 화면 세션 저장보다 먼저입니다. 세션 저장만 실패하면 준비한 문제 하나가 소진될 수 있지만,
학습 사건이나 DNA가 부분 저장되지는 않습니다. 한 브라우저 런타임의 동시 저장은 직렬화하며,
기기 간 동기화나 여러 브라우저 탭의 전역 트랜잭션은 구현하지 않았습니다.

데모 초기화는 데모 출제 이력만 초기화하며 실제 사용자 이력을 보존합니다.
Mock는 유한한 연습 문제이며 무제한 AI 생성으로 표시하지 않습니다.
