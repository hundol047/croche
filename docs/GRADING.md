## 재현한 오류와 수정

`y′+2y=0, y(0)=3`에 `3e^(-2x)`를 제출하면 이전 버전은 문자열 표기 차이로 오답 판정하고
부호 오류 DNA를 0→17로 누적했습니다. 현재는 `3e^{-2x}`와 같은 식으로 판정합니다.

## 지원하는 답

| 답 | 처리 |
|---|---|
| 숫자 하나 | 부호·소수·지수 및 단일 분수 `1/2` 허용. 동일 값 또는 오차가 min(10⁻⁶, 정답 절댓값×10⁻⁶)보다 작으면 인정 |
| 유한 구간 | 숫자 두 개와 (), []의 끝점 포함 여부를 각각 비교 |
| 지수함수 | `c*e^(k*x)` 형태. `3e^(-2x)`, `3*e^{-2*x}`, `3exp(-2*x)` 허용 |
| 정의되지 않는 값 | ‘정의되지 않음’, ‘정의 안 됨’, undefined 허용. 숫자 답은 오답 |
| 복수 선택 | 보기의 답을 쉼표로 구분. 순서·대소문자 차이 허용 |
| 그 외 텍스트 | 저장된 정답과 동일한 표기 및 단순 문자 출력 문제만 지원 |

계수·지수의 부호와 값을 구분하고 구간의 열린·닫힌 끝점을 유지합니다.
256자 초과, 깨진 괄호, 실행 코드, 지원 밖 복합 수식은 판정 불가입니다.
공백을 제거해 서로 다른 숫자를 이어 붙이지 않고, 숫자는 유효 숫자 최대 15자리로 제한합니다.
단일 분수의 분자·분모는 같은 숫자 문법으로 완전히 파싱합니다. 분모 0, 중첩 계산식, 무한값, 0으로 언더플로한 값은 판정 불가입니다. 정답 0은 정확히 0만 인정해 `1e-8`과 혼동하지 않습니다. 구간 끝점에도 단일 분수를 허용하되 열린·닫힌 끝점은 계속 구분합니다.
입력을 eval/Function으로 실행하거나 수식의 몇 지점만 대입해 동등성을 추정하지 않습니다.

일반 CAS가 아닙니다. 유리식·삼각함수·복합식·부등식·무한 구간 등의 다양한 동치 표기는 아직 지원하지 않습니다.
지원 밖 입력에는 오답 원인을 단정하지 않고 재입력 형식을 안내합니다.
과거 버전의 저장 기록은 자동으로 재채점하거나 삭제하지 않습니다.

## 반복 출제

기본 문제 7개는 유지하고, 추가 연습은 **과목당 30,000개, 총 90,000개**의 조건 조합 문제로 확장했습니다.
쉬움·보통·어려움별 10,000개이며 각 난이도에 5개 유형×2,000개 변형이 있습니다.
90,000개의 독립 집필이나 실제 AI 생성이 아닌 검증된 유형의 파라미터 연습입니다.
전체 유형·범위·정답 검증은 [문제 은행](PROBLEM_BANK.md)을 참고하세요.

유형별 다음 변형 번호를 사용자별 learning의 practiceProgress에 원자적으로 저장합니다.
숫자·조건을 바꿔 정답·해설을 구성하고, 문제를 한 개씩 계산하므로 수만 개의 JSON을 저장하지 않습니다.
기존 issued 이력은 보존하며 새 v2 문제 은행은 별도 ID·본문으로 관리합니다.
답을 제출하지 않아도 다음 출제에서 제외되고, 앱·서비스·저장 객체를 다시 만들어도 진행 번호가 유지됩니다.
소진된 유형·난이도는 비활성화하고 다른 난이도나 기본 문제로 안내합니다.
Trap은 기존 본문 이력에 출제를 기록하고 같은 문제의 재출제를 막습니다.
이미 열린 문제의 새로고침은 현재 문제를 복원하며 새 출제로 집계하지 않습니다.

출제 이력 저장은 화면 세션 저장보다 먼저입니다. 세션 저장만 실패하면 준비한 문제 하나가 소진될 수 있지만,
학습 사건이나 DNA가 부분 저장되지는 않습니다. 한 브라우저 런타임의 동시 저장은 직렬화하며,
기기 간 동기화나 여러 브라우저 탭의 전역 트랜잭션은 구현하지 않았습니다.

데모 초기화는 데모 출제 이력만 초기화하며 실제 사용자 이력을 보존합니다.
Mock는 유한한 연습 문제이며 무제한 AI 생성으로 표시하지 않습니다.


## 학교급·한국사 확장 후 채점과 저장

초·중·고·수능은 `school-v1`, 대학은 기존 `v2`를 사용합니다. 총 810,000개의 조건·지문 조합이며
숫자·수식·구간·복수 선택 채점은 기존 안전 문법을 유지합니다. 객관식 보기는 터치/키보드로 선택하거나
직접 입력할 수 있습니다. 보기의 번호를 임의로 정답 문장으로 바꾸지 않습니다.

각 학교급·과목·난이도·유형의 진행 번호와 최근 선택을 함께 저장합니다. 새로고침은 현재 문제와 선택을
복원하며, 학습 사건은 제출 ID로 중복을 막습니다. 학교 문제와 DNA의 학교급을 저장해 대학 Trap으로
잘못 넘어가지 않도록 합니다. 학교 Trap에 근거가 없는 오답은 중립 결과이며 HIT/DNA를 누적하지 않습니다.
지원하는 Trap 유형이 없으면 그 상태를 안내합니다. 모든 학교 약점에 Trap이 준비된 것은 아닙니다.

전체 구성·본문 기반 독립 정답 검증과 역사 검증의 한계는 [PROBLEM_BANK](PROBLEM_BANK.md)를 참고하세요.

## 원인 미확인 오답과 과목별 DNA

`6e^(-2x)`는 `3e^{-2x}`와 다른 계수이므로 오답이지만 부호 오류로 단정하지 않습니다. 제출과 정답 비교는 보존하고 화면에 **오답 원인 미확인 · Error DNA에는 반영하지 않았습니다.**를 표시합니다. 문제의 목표 오류나 자유 풀이 키워드만으로 원인을 정하지 않습니다. 지수함수의 계수가 같고 지수 부호만 반대인 경우, 지수가 같고 계수 부호만 반대인 경우와 내용이 일치하는 기존 기본 문항의 한정된 오답 근거만 사용합니다. 저장 경계에서도 이 근거를 다시 검사합니다. 일반적인 학습자의 심리 원인을 입증하는 모델은 아닙니다.

[계수 오답의 원인 미확인 화면](screenshots/remediation-neutral-coefficient-analysis-375.png)

새 DNA는 **학교급+과목+오류 유형**으로 누적·교정합니다. 같은 부호 오류라도 공업수학과 일반물리, 중학교와 고등학교 수학은 서로 점수를 바꾸지 않습니다. 이전 통합 점수는 `기존 통합 기록 · 과목별 재분류 전`으로 보존하고 새 교정·예측·Trap 대상과 현재 위험도/리포트 패턴 계산에서 제외합니다. 정보가 부족한 과거 점수를 임의로 나누거나 재채점하지 않습니다. 확실한 사건의 점수 공식과 제출 ID 중복 방지는 유지합니다.

예측에서 Trap으로 갈 때 과목·학교급·오류 유형을 함께 전달합니다. 생성 응답도 출제 예약 전에 요청 범위와 대조하고, 다른 과목이나 다른 목표 유형의 응답을 저장하지 않습니다. 대학 Trap은 다른 과목 템플릿으로 대체하지 않습니다. 일반물리 부호 훈련에는 방향 있는 변위 `−6 m`와 힘이 한 일 `−20 J` 문항을 추가했습니다. 각각 반대 부호 답만 해당 오류 근거로 인정하고 다른 숫자 오답은 중립입니다. 준비되지 않은 과목/패턴 조합과 기존 문제가 소진된 상태를 서로 다른 문장으로 안내합니다.
